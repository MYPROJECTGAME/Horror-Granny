# AI Engineer — NET

This file is a team task checklist for the Horror-Granny repository. Confirm actual implementation details against the current Unity project before changing code.

## Tasks
- [ ] Inspect the existing enemy AI, navigation, and player-detection code.
- [ ] Implement or refine patrol, detection, chase, search, and return states where appropriate to the current design.
- [ ] Tune detection range and movement; check obstacle handling and stuck states.
- [ ] Coordinate enemy events and game-over behavior with Backend.
- [ ] Record reproducible AI test cases for QA.

## Acceptance checks
- [ ] AI state transitions are testable and consistent.
- [ ] Enemy movement works in the intended scenes.
- [ ] No recurring console errors during tests.

## Pull request checklist
- [ ] Explain what changed.
- [ ] Include test steps and results.
- [ ] Link the related GitHub issue.
- [ ] Request review from the Project Manager before merging.
