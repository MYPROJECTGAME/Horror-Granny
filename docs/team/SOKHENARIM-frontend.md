# Frontend Developer — SOKHENARIM

This file is a team task checklist for the Horror-Granny repository. Confirm actual implementation details against the current Unity project before changing code.

## Tasks
- [ ] Inspect existing scenes, UI prefabs, and input setup before editing.
- [ ] Implement or polish menu, pause/resume, objective prompts, interaction prompts, and result screens as required.
- [ ] Connect UI to existing gameplay events without duplicating game logic.
- [ ] Check layout and readability at supported resolutions.
- [ ] Coordinate UI state expectations with Backend and QA.

## Acceptance checks
- [ ] Buttons and prompts work in the correct game states.
- [ ] UI remains readable at supported resolutions.
- [ ] No missing references or UI-related console errors.

## Pull request checklist
- [ ] Explain what changed.
- [ ] Include test steps and results.
- [ ] Link the related GitHub issue.
- [ ] Request review from the Project Manager before merging.
