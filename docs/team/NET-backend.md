# Backend Developer — NET

This file is a team task checklist for the Horror-Granny repository. Confirm actual implementation details against the current Unity project before changing code.

## Tasks
- [ ] Inspect existing Unity gameplay code before changing architecture.
- [ ] Implement and maintain gameplay state, objectives, item interactions, and win/game-over conditions as needed.
- [ ] Coordinate APIs, events, and shared scripts with the AI and Frontend developers.
- [ ] Document non-obvious logic and update relevant project documentation.
- [ ] Test changes in the Unity Editor and report exact test steps.

## Acceptance checks
- [ ] Changes compile without errors.
- [ ] Gameplay interactions behave consistently.
- [ ] Pull request describes changed files and manual tests.

## Pull request checklist
- [ ] Explain what changed.
- [ ] Include test steps and results.
- [ ] Link the related GitHub issue.
- [ ] Request review from the Project Manager before merging.
