# QA — RAMORN & MALIN

This file is a team task checklist for the Horror-Granny repository. Confirm actual implementation details against the current Unity project before changing code.

## Tasks
- [ ] Test launch, movement, interactions, objectives, enemy AI, pause/resume, and game-over/win flows.
- [ ] Record bugs with reproduction steps, expected and actual results, severity, and evidence where useful.
- [ ] Retest fixes and run regression checks.
- [ ] Check Unity Console errors, missing assets, broken references, and scene loading.
- [ ] Verify README and Wiki setup steps against the actual project.

## Acceptance checks
- [ ] Test cases and results are recorded.
- [ ] Bug reports are reproducible.
- [ ] Fixes are retested and a test summary is posted.

## Pull request checklist
- [ ] Explain what changed.
- [ ] Include test steps and results.
- [ ] Link the related GitHub issue.
- [ ] Request review from the Project Manager before merging.
