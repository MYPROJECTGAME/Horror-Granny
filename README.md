# Horror-Granny

Welcome to Horror-Granny, a spine-chilling survival horror game created by a passionate team of developers. Trapped inside a creepy house, you must find clues, solve puzzles, and collect keys to escape before Granny catches you. Every sound matters, so move quietly, hide wisely, and stay alert. Her hearing is sharp and her patience is thin!

## Getting Started

### Requirements

- Unity 2020.2.0f1
- Git, if you are cloning the repository

### Open and Play

1. Clone or download this repository.
2. In Unity Hub, select **Add** and choose the project folder.
3. Open the project with Unity 2020.2.0f1 and allow Unity to import the assets.
4. Open `Assets/HorrorEyes/HE Project/Scenes/GameStartScene.unity` and press **Play**.

### Build

The project build settings include `GameStartScene`, `MainMenu`, `LoadScene`, `Morgue`, and `School_Demo`. In Unity, open **File > Build Settings**, select the target platform, and build the project.
